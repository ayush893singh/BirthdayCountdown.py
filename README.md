# Birthday Countdown

A simple Python project that calculates your current age, the total number of days you have lived, and the number of days remaining until your next birthday.

---

Features

- Enter your birth date (day, month, and year)
- Calculate your current age
- Calculate total days lived on Earth
- Display the next birthday date
- Show the remaining days until your next birthday
- Display a birthday greeting if today is your birthday

---

Technologies Used

- Python
- "datetime" Module

---

Concepts Used

This project uses:

- Variables
- User Input
- Date Calculations
- Conditional Statements ("if", "else")
- Arithmetic Operations
- Output Formatting
- Python's Built-in "datetime" Module

---

Installation

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.

---

How to Run

python main.py

---

How It Works

1. Enter your birth day.
2. Enter your birth month.
3. Enter your birth year.
4. The program calculates:
   - Your current age
   - Total days you have lived
   - Your next birthday
   - Remaining days until your birthday
5. If today is your birthday, the program displays a birthday message.
